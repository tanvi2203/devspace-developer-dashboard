# DevSpace - Personal Developer Productivity Dashboard

DevSpace is a personal developer productivity dashboard created to help developers organise their tasks, projects, skills, and learning progress.

## Week 1

In Week 1, I created the basic structure and design of the DevSpace dashboard using HTML and CSS.

The dashboard includes:

- Sidebar navigation
- Statistics cards
- Today's tasks section
- Current projects section
- Skills progress section
- Development notes

## Week 2 - Responsive Web Design

In Week 2, I improved the DevSpace dashboard by making it responsive for different screen sizes.

The main updates include:

- Added CSS media queries
- Improved the layout for tablet screens
- Improved the layout for mobile screens
- Added a mobile navigation menu
- Adjusted cards and content for smaller screens
- Tested the website at desktop, tablet, and mobile sizes

## Technologies Used

- HTML
